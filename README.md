# 质检员训练室：信号检测论交互式实验

这是北京师范大学《工程心理学》作业一的个人项目。网页模拟工业零件裂纹检测任务，记录每次判断并计算信号检测论指标。

## 运行方式

无需安装依赖。下载或 clone 仓库后，直接双击 `index.html`，或在浏览器中打开它即可。

## 实验设计

- 信号：零件存在裂纹；噪声：零件没有裂纹。
- 先验概率：P(S)=50%。
- 每局20次正式试次；零件刺激限时呈现。
- 三档难度通过调整裂纹的可见程度体现。
- 四种结果：击中 H、漏报 M、虚报 FA、正确拒绝 CR。

## 结果计算

- `P(Hit) = H / (H + M)`
- `P(FA) = FA / (FA + CR)`
- `d′ = z(P(Hit)) - z(P(FA))`
- `c = -0.5 × [z(P(Hit)) + z(P(FA))]`
- `Accuracy = (H + CR) / N`

网页对0或1的极端比例采用边界修正，避免正态反函数出现无穷值；原始四格计数仍完整展示。
